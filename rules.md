Saya sedang membangun project portfolio bernama **SkillMap AI** dan saya ingin **BELAJAR CODING SAMBIL MEMBANGUN PROJECT**, bukan sekadar menerima kode jadi.

Konsep aplikasi:

User upload CV PDF + paste Job Description → AI menganalisis kecocokan skill → menampilkan matched skills, partial skills, missing skills → memberikan rekomendasi skill yang perlu dipelajari.

Tech stack:

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase
* PostgreSQL
* Supabase Auth
* Supabase Storage
* Supabase Edge Functions
* Gemini API
