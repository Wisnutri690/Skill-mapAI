# SkillMap AI - Backend

Direktori ini disiapkan untuk backend service **SkillMap AI** menggunakan Supabase:

- **Supabase Storage**: Bucket penyimpanan dokumen CV (PDF).
- **Supabase Database**: Skema tabel PostgreSQL untuk menyimpan hasil analisis & riwayat.
- **Supabase Edge Functions**: Serverless functions untuk integrasi aman dengan Gemini API.

### Panduan Awal
Folder ini akan diinisialisasi menggunakan Supabase CLI saat memasuki Tahap 10:
```bash
supabase init
```
